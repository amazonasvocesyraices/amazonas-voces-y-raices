# Amazonas Voces y Raíces

En la cabecera se muestra el emblema circular `images/logo.png` junto al nombre «Amazonas / Voces y Raíces» como texto HTML independiente.

Abre `index.html` en el navegador para ver la página. Para GitHub Pages, sube `index.html`, `style.css`, `script.js` y la carpeta `images` a la raíz del repositorio. No cambies los nombres ni las rutas.
