# Amazonas Voces y Raíces

Versión con el emblema sin letras en la esquina superior izquierda.

## Abrir localmente
Abre `index.html` desde esta carpeta sin mover `images`. Algunas fotografías externas requieren conexión a internet.

## Publicar en GitHub Pages
Sube `index.html`, `style.css`, `script.js` y la carpeta `images` a la raíz del repositorio y confirma los cambios. No subas la carpeta contenedora como un nivel adicional. Si aparece la versión antigua, recarga con Ctrl+F5.
